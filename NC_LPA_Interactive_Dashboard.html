NC License Plate Agency Access Dashboard

This prototype visualizes access to License Plate Agencies (LPAs) across North Carolina. Each Census block group is shaded by how far its population-weighted centroid is from the nearest active LPA. You can filter LPAs by tier and rating, toggle locations on or off, and see how those changes ripple through access metrics in real time.

What you see
Block groups colored by distance bands to the nearest LPA, plus facility markers sized by tier and colored by rating.
What you can test
Turn LPAs on/off, change filters, and track how population coverage and weighted average distance change between the baseline and current scenarios.

How to use this dashboard

  1. Click the Interactive Dashboard tab at the top to open the map view.
  2. Use the Filters panel to search LPAs by name, rating, or tier.
  3. Toggle LPAs on/off to see how the Statistics panel and map colors respond.
  4. Hover or click on map features and LPA markers to inspect local details.

When you are ready, switch to the Interactive Dashboard tab to explore scenarios.
